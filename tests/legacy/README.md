# Legacy Version-Specific Tests

These scripts are archived from v0.3.x releases for traceability. Several assert exact historical version numbers/source layouts and are **not** part of the v0.4.0 executable QA suite; running them unchanged against v0.4.0 can fail by design.

Current v0.4.0 QA lives in:

- `tests/unit/test_v040.py`
- `tests/unit/test_v040.mjs`
- `tests/integration/test_export_v040.mjs`
- `tests/regression/test_exact_sfa_legacy.mjs`
